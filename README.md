CommunityPulse

## Overview

CommunityPulse is a web application that helps organizations understand how their members feel about different issues in their community. Many leaders do not always know what people are experiencing or thinking until problems grow bigger. This platform allows members to share feedback easily while giving leaders useful insights from the data.
CommunityPulse collects feedback from users and analyzes the emotional tone of each message. The system then shows overall trends and patterns so leaders can make better decisions and solve problems earlier.
The goal of this project is to demonstrate software engineering skills by building a real world application that combines web development data storage and basic sentiment analysis.

## Purpose

Organizations such as schools churches student groups and local communities often struggle to gather honest feedback from members. People may hesitate to speak openly or their concerns may not reach the right leaders.
CommunityPulse provides a safe and simple way for members to submit anonymous feedback. Leaders can then view the results through a dashboard that shows common issues emotional tone and patterns over time.

This helps organizations listen better respond faster and build healthier communities.

## Main Features

User account creation and login system
Anonymous feedback submission
Sentiment analysis to detect positive neutral or negative tone in feedback
Admin dashboard showing trends and common concerns
Search and filter feedback by date or category
Data visualization using charts
Downloadable reports
